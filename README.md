# Alphi Teklif Oluşturucu (Quote Generator) 🚀

[TR] Modern ajanslar ve freelancerlar için geliştirilmiş, hızlı ve PDF odaklı bir teklif oluşturma aracıdır.
[EN] A modern, fast, and PDF-focused quote generation tool designed for agencies and freelancers.

---

## ✨ Özellikler / Features

### 🇹🇷 Türkçe
- **Anlık Önizleme:** Yazılan her veri anında PDF şablonu üzerinde güncellenir.
- **Dinamik Hesaplama:** Ara toplam, KDV (%20) ve indirim kalemleri otomatik hesaplanır.
- **Sömestr Modu:** İndirimli kalemler için özel görsel vurgu (Kırmızı animasyon).
- **PDF Export:** Tek tıkla profesyonel A4 formatında çıktı.

### 🇺🇸 English
- **Live Preview:** Real-time synchronization between the editor and the PDF template.
- **Auto-Calculation:** Automatic calculation for subtotals, VAT (20%), and discounts.
- **Semester Mode:** Special visual feedback (red highlight animation) for discount rows.
- **PDF Export:** High-quality A4 PDF generation with a single click.

---

## 🛠️ Teknik Yığın / Tech Stack

- **Frontend:** HTML5, Tailwind CSS (Custom Dark/Light Mode)
- **Engine:** Vanilla JavaScript (DOM & Logic)
- **Library:** [html2pdf.js](https://github.com/eKoopmans/html2pdf.js)
- **Typography:** Manrope via Google Fonts

---

## 🚀 Kullanım / Usage

[TR] Kurulum gerektirmez. `index.html` dosyasını tarayıcıda çalıştırmanız yeterlidir.
[EN] No installation required. Simply open `index.html` in your favorite browser.
